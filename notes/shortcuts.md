# Keyboard shortcuts

Phrases are from the Deluxe Paint IV manual, Appendix B and the animation
keys. "done" means this program does that action. A shortcut is ignored
while the load/save path field is focused.

## Painting modes

| Key | Manual phrase | Status |
| --- | --- | --- |
| F1 | Matte. Uses a custom brush in its original form. Background color of the brush is transparent. | done |
| F2 | Color. Uses the shape of the brush and fills it with the current foreground color. | done |
| F3 | Replc. Uses the custom brush in its original form, except that no colors are transparent. | done |
| F4 | Smear. Smears any colors on the page when you drag a brush over them. | done |
| F5 | Shade. Paints the next color in the cycle range. Right button paints the previous color. | done |
| F6 | Blend. Averages colors under the brush. | done |
| F7 | Cycle. Cycles through the colors in the current range as you draw. | done |
| F8 | Smooth. Softens hard lines. | done |

## Toolbox

| Key | Manual phrase | Status |
| --- | --- | --- |
| > | Increase magnification | done |
| < | Decrease magnification | done |
| / | Toggle Symmetry on/off | done |
| , | PICK color cursor | Comma steps to the previous animation frame instead, as requested. |
| [ and ] | Change foreground color | done |
| ( and ) | Change background color | done |
| p | Palette Mixer on/off | done |
| P | Palette Arrange on/off | done |
| TAB | Cycle on/off | done |
| l | LightTable on/off | done |
| Alt-l | LightTable Dim on/off | done |
| Alt-p | Process on/off | done |
| Alt-t | Translucency on/off | done |
| M | Anim Move requester | done |

The Grid, Magnify, and Zoom controls are the toolbox buttons. The manual
says the Grid restricts painting to the grid points, Symmetry paints
symmetrically, Magnify shows a rectangle then splits the page, and a click
on Zoom increases magnification while a right-click reduces it.

## Animation

| Key | Manual phrase | Status |
| --- | --- | --- |
| 1 | Previous frame | done |
| 2 | Next frame | done |
| . | Next frame (same step as 2) | done |
| , | Previous frame (same step as 1) | done |
| 3 | Display the Go To Frame requester | done |
| Alt-a | Anim Control Panel on/off | done |
| 4 | Play continuously until space or the mouse | done. Space stops. Pressing 4 again also stops. |
| 5 | Play once | done |
| 6 | Ping-pong | done |
| 7 | Previous AnimBrush cel | done when an AnimBrush is loaded |
| 8 | Next AnimBrush cel | done when an AnimBrush is loaded |
| Shift-1 | First frame | done (the shifted key arrives as !) |
| Shift-2 | Last frame | done (the shifted key arrives as @) |
| Shift-4 | Play reverse continuously | done (the shifted key arrives as $) |
| Shift-5 | Play once reverse | done (the shifted key arrives as %) |
| Space | Stops playback | done |
| Left arrow | While playing, slows the frame rate. Otherwise scrolls the page. | done |
| Right arrow | While playing, speeds the frame rate. Otherwise scrolls the page. | done |
| Up / Down | Scroll the page | done |
